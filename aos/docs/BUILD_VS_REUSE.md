# Build vs Reuse - audit of 15 repositories (2026-11-17)

Method: shallow-cloned each repo into an isolated scratch dir (nothing executed from them), collected facts with `aos/scripts/audit_repo.py` (HEAD date, license text, size, manifests, tests, risk-pattern greps), then read the code behind each claim that mattered. README claims were **not** trusted; items marked **verified** were confirmed in code, by tests, or by running. Confidence tags: [H] verified in code/run, [M] read in code, not run, [L] README/inference only.
"Maintenance" = HEAD commit date of the audited clone; stars/issue health were not assessed.

## Overlaps and what not to duplicate
- Workflow methodology (brainstorm/plan/TDD/review/worktrees): **Superpowers** owns it; AOS only adds cost/context/memory/handoff around it.
- Skill catalogues (ECC, wshobson): do not copy; install individual reviewed skills if wanted.
- Observability server (Langfuse) vs local JSONL metrics: choose local by default.
- Memory (mem0) vs JSONL: JSONL wins on privacy/provenance; mem0 only if semantic recall is proven necessary.

## Requirement check: Claude Code vs Codex
See `COMPATIBILITY.md`. Net: skills = Agent Skills standard (both); agents = Claude `.md` / Codex `.toml` (generated); commands = Claude only (exported as skills); instructions = AGENTS.md (both). Live loading inside Codex was **not** verified here.

Risks: third-party Codex limits are unverified; benchmark numbers are context-level proxies (below); external repos change - pins in `REUSE_LOG.md`.
